# 波尔振动
来源S1/S3；课堂细节为摘要转述，使用时核本次资料。
- ω/ω0=T0/T；10T记录先除10。公式反而数值正确，仅改错的部分。
- βi=ln(θi/θ(i+k))/(kT)，核峰值配对、k、T，单位s^-1。
- 独立重复量的均值A类：sqrt(sum((xi−xbar)^2)/(n(n−1)))；共享输入/系统趋势需核适用性。课堂指定方法明确标口径。
- 位移相位减驱动力相位则滞后为负；滞后角大小为正也可，需定义一致。
- 本课堂摘要取90°滞后对应驱动周期为T0，不把初调周期自动等同。
- 两方向正幅值用平均；带符号极值振幅为(θmax−θmin)/2，先核符号。
- 恒定驱动力、线性黏性阻尼位移响应：θ=A/sqrt((ω0²−ω²)²+4β²ω²)。非零峰ωr=sqrt(ω0²−2β²)，需β<ω0/sqrt(2)。
- 弱阻尼半峰宽：θmax/sqrt(2)交点r1,r2，β≈π(r2−r1)/T0；不是无条件精确恒等式。
- 历史图θmax=103.399°，辅助线约73.114°，r1=.9821,r2=1.0187,T0=1.5115 s，β约.0761 s^-1；不得作为新数据。
- 上述相位定义关键点(1,−90°)。稳态同频不要求共振。
reported操作：1000 Hz，0°/90°校准，手动最好不超170°，有阻尼尽量不超150°，600—700 mA，前后阻尼相同，采集超过11周期选中间10峰，稳态读数，频闪60 s，两次差超5°校准。使用前核本次仪器和课件。
