# 审查模式
1. 列实际可读材料/页、必做项目；无题目原文不声称全部小问已核。
2. 确定本次公式、格式和来源；已引用原始单不判漏表。
3. 用脚本复算关键量，核符号、代入、单位、精度与数量级。
4. 核图表同源、辅助线交点真实存在；看图面而非仅代码。
5. 核各小问的物理依据、条件、误差机制和改进对应性，不按条数评质量。
6. 对每项怀疑返回原文/原图，区别PDF页序与纸上页码，无法确定就用标题/原文定位。
7. 对完整要求清单核覆盖，避免只找到几处问题就结束。

输出：位置｜原文/数值｜分类和依据｜具体修改。
- 明确错误/遗漏：可定位且有可靠依据、复算证据；给可直接替换内容。
- 需要核实：字迹不清、缺资料、范围不明、条件矛盾；指出待核实项而不定罪。
- 优化建议：表达或排版改善，没有证据不能称必改/会扣分。
最后说明可保留内容及未检查范围。不凭空评分，不承诺满分。

误报防线：课堂11.6不能因教材11.61判错；课堂指定逐差均值+相邻差算法不直接替换，可另解释统计适用性。
根式外有V不强加根内V²；表头有单位不每格补；旧OCR撤回不再改数据。
相位先查定义，各自一致可保留，混用才指出具体位置。仅计A类不强加B类。
历史“过简扣3分”不是少于3条扣3分。公式错而数值图正确时改公式，不要求重画正确图。
