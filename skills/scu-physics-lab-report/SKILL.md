# SCU物理实验报告

## 入口和按需读取
- 撰写：读取 [writing.md](references/writing.md)，成稿后按 [review.md](references/review.md)复核。
- 检查：读取 [review.md](references/review.md)，先核对来源，后复算，不直接修改用户文件。
- 学习：读取 [learning.md](references/learning.md)，仅将有依据的反馈写入规则。
- 同时有批改与新报告：先学习已确认规则，再处理新报告。
- 所有模式读取 [evidence.md](references/evidence.md) 和 [preferences.md](references/preferences.md)。
- 按实验读取：[弗兰克—赫兹](references/franck-hertz.md)、[波尔振动](references/pohl.md)、[超声与弹簧振子](references/doppler-spring.md)。历史案例不是本次数据或全课程规定；先匹配课程、实验、老师及批次，无法匹配就仅作参考。
- 学习和历史争议时读取 [feedback.jsonl](references/feedback.jsonl) 与 [sources.md](references/sources.md)。
- 计算见 [calculation.md](references/calculation.md) 与 `scripts/lab_calc.py`。只有覆盖的模型才调用；其他模型按本次公式写临时脚本独立复算，不能硬套。

## 固定执行流程
1. 确定实验、模式、指定板块和交付形式。只输出用户要求的范围。
2. 建立材料清单和要求清单：文件、页码、原始数据、题目各小问、课堂公式、图表及格式。标明实际读取范围，不凭摘要声称读过原件。
3. 建统一数据表，保留原始精度、单位、倍率、自动/手动组别、来源、确认状态与修订。已确认数据直接使用；仅对影响结果的模糊项询问。用户要求先核对再处理时遵守。
4. 选择适用规则并记录依据。先核对符号、理论值、统计样本数和正负号定义。
5. 用脚本复算关键数值并保留未修约结果，核对量纲和数量级。展示公式、必要代入、结果及单位，不能只报脚本答案。
6. 交叉核对原始记录、派生数据、公式、图、最终结果和文字；一处更正更新所有依赖项。
7. 回到原材料复核疑似错误。手写/扫描提取不足时必须看渲染图并放大；仍不清楚就标待核实。
8. 输出正文或按位置排列的审查结果，简短说明未核实关键内容。材料不足只暂停受影响部分。

## 准确性底线
- 不捏造测量数据、现象、操作经历、老师规定、页码、评分和来源；不挪用参考报告作者或历史案例数据。
- 不为理论吻合或曲线平滑改测量值；不把插值/拟合点当实测点。
- 本次课堂要求决定评分合规性。数学/物理矛盾需分开说明课堂写法与待核实的科学问题，不宣称错误公式普遍正确，不悄悄替换算法。
- 识别不清不等于记录错误；确认数据不因旧OCR再次质疑，新明确矛盾仍需指出证据。
- 检查完整等式、表头和倍率中的单位，不机械要求每项重复；无量纲量不加物理单位。
- 区分A类、B类、合成、扩展不确定度；缺仪器指标不编B类；只要求A类不强加B类。
- 科学图用代码生成并查看实际图像，不用生成式图片代替精确曲线或光路。先选模型，不能自动高阶拟合。
- 不把润色或详细写法当必改，不按历史个案推算固定扣分。
- 不承诺满分或普遍准确率；测试仅代表已测案例，不代表OCR或所有实验。

## 输出与持久更新
- 默认中文可直接抄写，正文与待确认提示分开。生成Word/PDF时调用相应技能并保存。
- 检查：位置｜原文/数值｜判断及依据｜具体修改；区分明确错误、需核实、可选优化，末尾说明可保留内容及范围。
- 学习须实际更新文件、验证、提交并同步仓库，不只说记住了。默认仅保存规则与去身份化案例，不上传原始学生报告。
- GitHub保存、本地安装、其他会话可发现性分别验证，不把上传等同所有聊天自动可用。

- 公共项目为SCU-physics-lab-report，非学校官方产品。使用者的个人数据和新批改反馈默认只保存到自己的工作副本；不得自动向公共仓库提交个人报告或课堂资料。修改公共规则应经使用者授权提交Pull Request，由维护者审核。
