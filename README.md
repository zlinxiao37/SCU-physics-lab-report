# SCU物理实验报告

面向大学物理实验报告的 AI Skill：撰写报告、检查扣分风险、学习批改反馈。**学生自用交流项目，非四川大学官方发布或评分标准。**

## 文件位置
完整 Skill 在 `skills/scu-physics-lab-report/`，请保留其中的 `SKILL.md`、`agents`、`references`、`scripts`，不要只复制主文件。

## 使用
在支持自定义Skill的工具中安装上述完整文件夹，然后输入：
- `使用 $scu-physics-lab-report，按课堂要求完成数据处理。`
- `使用 $scu-physics-lab-report，检查报告的扣分风险。`
- `使用 $scu-physics-lab-report，学习这次老师批改，但只更新我的个人副本。`

安装位置由具体工具决定；GitHub公开不代表所有聊天平台会自动加载。若工具不支持Skill，可以提供SKILL.md和当前任务所需的references作为说明，但不能声称已完整安装。

请同时提供本次原始数据、题目及课堂要求。模糊字迹先核实，计算由脚本复算。科学图应使用代码，不用生成式图片代替。

## 能力与验证
包括21项标准库Python计算测试，涵盖不确定度、逐差法、衰减、半峰宽近似、线性拟合与修约。运行：

```sh
python skills/scu-physics-lab-report/scripts/test_lab_calc.py
```

上游开发还对审查、写作和规则学习做过文本任务验证。公开版经过改名和去身份化；没有真实手写OCR全流程测试，不能保证满分或零误判。

## 课程规则
案例中的11.6 V、特定A类算法、操作参数只适用于其对应条件。每次以本次老师要求为准，同时区分评分口径与数学物理适用性。

## 共同改进
可以Fork后修改自己的版本，并提交Pull Request。公开仓库不会自动给访客写入权限。请不要提交姓名、学号、签字、个人报告原件、账号密钥或未经授权的教师资料；个人反馈先保存在自己的副本。
